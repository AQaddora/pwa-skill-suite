# Phase 3 — Skills, README, Installer, CI Implementation Plan

> **For agentic workers:** Implemented inline via superpowers:executing-plans, task-by-task, TDD where code is involved. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the eight remaining PWA skills, the public README, MIT LICENSE, an idempotent installer, and a coverage CI job that keeps the README honest.

**Architecture:** Each skill is a `skills/<name>/SKILL.md` doc in the Phase-1 house style, citing catalog IDs so guidance and enforcement cannot drift. A machine linter (`skills/lint-skills.mjs`) enforces that invariant; CI runs it alongside the catalog tooling. The README's coverage numbers are generated by `packages/catalog/stats.mjs`, never hand-typed.

**Tech Stack:** Node ≥18 (ESM `.mjs`, `node --test`), GitHub Actions, POSIX bash.

## Global Constraints

- Path ownership: only `skills/` (every skill except `pwa-verify` and `pwa-audit`), `README.md`, `LICENSE`, `install.sh`, `.github/`, and this plan / `PROGRESS-phase3.md`. Never touch `packages/**` or `catalog.json`.
- Every rule a skill enforces cites its catalog ID(s) (`P-###`) verbatim from `packages/catalog/catalog.json`.
- Skills work standalone; detect superpowers by capability (is the skill invocable?), never by sniffing plugin paths. Document both modes.
- `pwa-native-feel` must refuse to emit `user-scalable=no` / `maximum-scale=1` and fail on sight (P-701); input zoom fixed with 16px fonts (P-101); double-tap zoom with `touch-action: manipulation` (P-110). `user-select: none` on chrome only (P-111, P-702).
- Five outcomes, per `packages/report/outcomes.mjs`: `PASS` / `FAIL` / `UNVERIFIED` / `N/A` / `BLOCKED`. `UNVERIFIED` exists because Playwright WebKit ≠ iOS Safari.
- English only in all docs, code, comments, PR text. MIT license.
- Branch `feat/phase3-skills-readme-ci`; commit working increments and `git push gh feat/phase3-skills-readme-ci` after every commit.

### Task 1: `skills/lint-skills.mjs` — the drift linter (test-first artifact)

**Files:**
- Create: `skills/lint-skills.mjs`

**Interfaces:**
- Produces: CLI `node skills/lint-skills.mjs` → exit 0 when every `skills/*/SKILL.md` has YAML frontmatter with non-empty `name` (matching its directory) and `description`, the description contains at least one quoted trigger phrase, and every `P-\d{3}` token cited anywhere in the body exists in `packages/catalog/catalog.json`. Exit 1 with a per-file diagnostic otherwise.
